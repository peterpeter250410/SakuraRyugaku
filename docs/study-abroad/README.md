## 核心业务流程（一句话）

```
学生注册登录 → 提交基础信息(预算+专业) → 系统自动匹配院校 → 推送推荐
   → 学生选校 → 上传申请资料(加密存储) → 顾问后台管理入库
```

## MVP（最小可用产品）范围

1. 官网基础展示（首页/服务/联系/院校公开页）
2. 学生注册/登录/个人中心
3. 基础信息表单（预算 + 专业）
4. 院校库（后台管理 + 专业子项 + 匹配字段）
5. 自动匹配引擎（预算 + 专业加权）
6. 推荐结果展示 + 推送 + 选校
7. 申请资料上传 + 加密存储 + 受控下载
8. 顾问/管理后台（分级权限 + 资料审核）
9. 站内 + 邮件通知
10. 多语言底座（注册表 + 切换器 + UI i18n）
11. 安全合规（加密/权限/同意书/HTTPS/加固）

> 完整功能编号见 [FEATURES.md](FEATURES.md)。
