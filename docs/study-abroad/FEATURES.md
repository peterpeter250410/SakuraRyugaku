## 本阶段（市场验证版）目标

> 当前阶段核心目标是 **市场验证**：以完整 MVP + 落地页投入市场，通过白帽 SEO 获取流量，
> 用数据判断「项目是否值得继续投入」。因此本清单新增 **L. 落地页模块** 与 **M. SEO 与数据分析模块**，
> 并明确本阶段交付范围。

**本阶段交付范围（市场验证）**：
- 完整 MVP 的全部 P0 功能（A~K）
- **落地页（L）**：全新留学主题设计，PC + H5 响应式，核心转化 = 填写意向信息
- **SEO 与数据分析（M）**：白帽 SEO 部署 + GA4 + Search Console + 自建埋点
- 支持终端：**PC + H5**（App 列入下一阶段）

**验证成功判据（示例，详见 ANALYTICS.md）**：
- 一定周期内的 UV/PV 达到预期
- 落地页转化率（意向信息提交 / UV）达到阈值
- 获取到足量「有实际意向的学生资料（含联系方式 + 意向信息）」

## L. 落地页模块 ★本阶段核心

> 落地页是市场验证阶段的**核心转化载体**：投放/SEO 带来的流量最先落到这里，
> 目标是引导访客**填写意向信息**，成为「有实际意向的学生资料」。PC + H5 双端响应式。

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| L-01 | 落地页主视觉（Hero） | P0 | 全新留学主题设计，强价值主张 + 首屏 CTA |
| L-02 | 价值卖点区 | P0 | 免费匹配、专业顾问、成功案例、日本院校资源等卖点 |
| L-03 | 服务流程说明 | P0 | 图示化「填信息→免费匹配→选校→申请」流程 |
| L-04 | 意向信息表单（核心转化） | P0 | 姓名+联系方式+预算+意向专业等，提交即线索 |
| L-05 | 表单多步/单页可选 | P0 | 降低填写门槛，移动端优先 |
| L-06 | 信任背书区 | P1 | 合作院校 Logo、学生评价、数据展示 |
| L-07 | FAQ 区 | P1 | 消除留学决策顾虑，利于 SEO 长尾 |
| L-08 | 悬浮/多处 CTA | P0 | 滚动跟随的咨询/表单入口，H5 底部固定条 |
| L-09 | 在线咨询入口 | P1 | LINE/微信/WhatsApp 引导（预留渠道） |
| L-10 | 落地页多版本（A/B） | P1 | 支持多套落地页对比转化（不同卖点/标题） |
| L-11 | H5 响应式适配 | P0 | 移动端布局、触控、加载优化 |
| L-12 | 落地页加载性能优化 | P0 | 首屏快开（图片懒加载、关键 CSS），利于 SEO 与转化 |

## MVP 范围汇总（P0 功能）

MVP 需闭环以下最小功能集：

1. **官网**：首页、服务、联系、院校公开展示（A-01/02/04/06）
2. **账号**：注册、登录、找回密码、个人中心（B-01~04）
3. **信息采集**：基础信息表单（预算+专业）、校验（C-01/04）
4. **院校库**：数据模型、后台管理、专业子项、详情展示、匹配字段（D-01/02/03/05/06）
5. **匹配引擎**：触发、预算匹配、专业匹配、评分排序（E-01~04）
6. **推荐选校**：结果展示、推送、选校、触发资料提交（F-01/02/04/06）
7. **资料提交**：清单、上传、加密存储、校验、受控下载（G-01/02/03/04/07）
8. **后台**：学生列表分级、详情、资料审核（H-01/02/03）
9. **通知**：站内 + 邮件（I-01/02）
10. **多语言底座**：架构、切换器、界面 i18n（J-01/02/03）
11. **安全合规**：加密、权限分级、同意书、HTTPS、防越权、基础加固（K-01/02/03/06/07/08）
12. **落地页**：主视觉、卖点、流程、意向表单、悬浮 CTA、H5 适配、性能、感谢页（L-01~05/08/11/12/13）
13. **SEO 与分析**：SEO 基础、关键词映射、性能、GA4、Search Console、自建埋点、转化事件、UTM（M-01/04/05/06/07/08/09/10）

## 本阶段（市场验证版）开发优先级

> 在完整 P0 基础上，落地页与数据埋点是**验证闭环**的最高优先级，需最先可用：

**第一梯队（验证闭环，最先上线）**：
- L 落地页 + L-04 意向表单 + L-13 感谢页
- M SEO 基础（M-01/04/05）+ GA4/SC/自建埋点（M-06/07/08/09/10）
- I 通知（表单提交后通知顾问）
- K 安全合规基础（表单防刷、隐私同意、HTTPS）

**第二梯队（业务完整性）**：
- B 账号、C 信息采集、D 院校库、E 匹配、F 选校、G 加密资料、H 后台

> 说明：落地页可**独立于账号系统**先跑（免注册留资），账号/匹配/资料等完整流程随后接入，
> 保证「最快验证市场」与「完整 MVP」两个目标兼顾。
