# WordPressBase 推荐插件清单

## 必装插件（P0）

| 插件名 | 用途 | 安装方式 |
|--------|------|----------|
| Wordfence Security (免费版) | WAF 防火墙 + 恶意软件扫描 | 后台搜索安装 |
| UpdraftPlus | 备份与恢复（配合脚本备份做双重保障） | 后台搜索安装 |

## 可选插件（P2）

| 插件名 | 用途 | 场景 |
|--------|------|------|
| WPForms Lite | 联系表单 | 企业官网需要联系表单时 |
| TablePress | 表格展示 | 需要展示产品参数等表格数据时 |
| EWWW Image Optimizer | 图片压缩优化 | 图片较多的展示站 |

## 禁止安装的插件类型

- **文件管理器类插件** - 安全风险极高，可被利用上传恶意文件
- **数据库管理类插件** - 使用宝塔面板自带的 phpMyAdmin
- **未更新超过 2 年的插件** - 可能存在未修复的安全漏洞
- **来路不明的付费插件破解版** - 极大概率包含后门

## 插件管理原则

1. 最小化原则：只安装必要的插件，插件越少安全风险越低
2. 及时更新：插件有更新时尽快更新（先在测试环境验证）
3. 定期审计：每季度检查一次已安装插件，移除不再使用的插件
4. 来源可靠：仅从 WordPress 官方插件库或可信开发者处获取
