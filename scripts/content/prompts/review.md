# 阶段 4：质量评审

给这篇稿子打分，判断它够不够格发布。

## 先说这一步的局限

你是在评审同一个模型体系写出来的稿子。模型评自己的输出有系统性偏高倾向 ——
这不是靠"请你严格一点"能消除的。

所以这份评分**不是**发布的唯一依据。真正有约束力的是机器闸门：
来源逐个抓取核对、数字逐个在来源页上比对、与站内已有文章算相似度。
那些是客观的，过不了就是过不了。

你这一步补的是机器查不了的部分：**这篇文章对读者有没有用**。
请按这个定位打分，不要复述机器已经查过的东西。

## 评分维度

每项 0–5 分。

**1. 信息增益（information_gain）**
读者在搜索结果前三名里读不到、而这篇给了的东西有多少？
- 0 = 通篇是其它文章都有的内容
- 3 = 有一两个别处少见的实用点
- 5 = 有明确的、别处基本没有的信息，且对决策有用

**2. 可操作性（actionability）**
读者读完能做什么？
- 0 = 只有原则和概念
- 3 = 知道大致该往哪个方向走
- 5 = 知道下一步具体做什么、找谁、准备什么

**3. 意图匹配（intent_match）**
标题承诺的和正文给的是不是同一件事？摘要有没有超出正文的承诺？

**4. 结构（structure）**
小标题能不能让人扫一眼就找到自己要的那段？重要的信息是不是被埋在后面？

**5. 诚实度（honesty）**
- 有没有把不确定的事说得很确定？
- 有没有暗示本站与学校有合作关系、能影响录取、或代收学费？（这些都是红线）
- 有没有虚构的第一人称经历？
- 不确定的地方有没有如实标出？

诚实度这项**如果低于 4 分，整篇直接不合格**，不管其它项多高。

## 输出

只输出 JSON，不要任何其它文字，不要用 ``` 包裹：

```
{
  "scores": {
    "information_gain": 0,
    "actionability": 0,
    "intent_match": 0,
    "structure": 0,
    "honesty": 0
  },
  "total": 0,
  "verdict": "publish" | "revise" | "reject",
  "blocking_issues": ["必须修掉才能发的问题"],
  "suggestions": ["可改可不改的建议"],
  "strongest_point": "这篇最有价值的地方是什么",
  "weakest_point": "最弱的地方是什么"
}
```

判定标准：
- `honesty` < 4 → 一律 `reject`
- `total` < 15 → `reject`
- `total` 15–19 → `revise`
- `total` ≥ 20 且无 blocking_issues → `publish`

不要为了让稿子过关而放宽标准。打回去重写的成本远低于发布一篇没用的文章 ——
后者会拖累整站在搜索引擎眼里的质量评价。
